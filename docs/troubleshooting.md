# Troubleshooting

If you experience any of the following issues, please try the suggested troubleshooting steps.

## I can't log in {#I-cant-log-in}

* Make sure you use the correct login method set up by your organization:

  + Username and password
  + Single sign-on
  + Windows account
* Contact your system administrator to see if system is fully running and your account is active

## I forgot my password {#I-forgot-my-password}

* Ask your system administrator to reset password

## Application won't load {#Application-wont-load}

* Make sure you use a supported browser (Google Chrome or Microsoft Edge)
* Update your browser to the latest version
* Clear your browser’s history and cache
* Disable any browser extensions you have turned on
* Test for the issue in another supported browser to see if the issue is isolated to only one browser
* Contact your system administrator for further assistance

## Application got frozen {#Application-got-frozen}

* Refresh the page (**F5** or **Ctrl+R**)
* Restart browser

## Missing permissions {#Missing-permissions}

## No map is displayed {#No-map-is-displayed}

Depending on selected map source:

* Local map: contact your system administrator to check if the local map service is running
* Public map service: Make sure you have internet access

## Dialog is locked by somebody else {#Dialog-is-locked-by-somebody-else}

Some configuration dialogs can be opened exclusively by a single user to avoid concurrent changes. When first user opens such a dialog, other users will see it as locked.

To access a locked dialog:

* Wait a few minutes until the dialogue is unlocked again
* If the system persists, ask your system administrator to force unlock the dialog

## Message "Not enough licenses" is displayed {#Message-Not-enough-licenses-is-displayed}

* Contact your system administrator to check whether

  + Application licenses are expired or incorrectly set up
  + Number of data objects exceeds the allowed limit

## Session won't get restored after next log in {#Session-wont-get-restored-after-next-log-in}

Your browser may block opening detached tabs or windows by default.

To allow pop-up windows:

* In Google Chrome:

  + 1. In the address bar, click Pop-up blocked icon
  + 2. Select site URL you want to check
  + 3. Select Always allow pop-ups and redirects from [site]
* In Microsoft Edge:

  + 1. Go to Settings > Cookies and site permissions
  + 2. Under All permissions, select Pop-ups and redirects
  + 3. Go the Allow section, and add site URL

## I get logged out every night {#I-get-logged-out-every-night}

For security reasons, all users are logged out no later than 24 hours after logging in.

## I can’t find System status {#I-cant-find-System-status}

System status overview is now accessible via System monitoring menu.
