# Configuration UI

We have created a simple UI that helps to configure SAF. The UI is available under: `symphony.${BASE_DOMAIN}/config`

## How to use the configUI

1. Go to the Configuration UI (you need to be signed in and have the role “1“ → Basic_Visualize)
2. Choose which modules the customer needs in the top menu
3. Choose which modules is needed in the LHS menu
4. Change the order if required
5. Choose a default language
6. Choose the optional languages
7. Copy the generated `values.yaml` and paste inside SAF in the customer GitLab project

> Note: The config UI does not cover 100% of what can be configured in SAF. You can check the "Deployment Configuration"
> table below, if you require more configuration options.
