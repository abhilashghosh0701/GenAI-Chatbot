# Application overview

Symphony is a modern web-based traffic management platform that enables cities to solve their specific traffic challenges. It helps them ensure safety of all road users, limit the impact on the environment and increase their quality of life.

Symphony is based on a modular concept: Base modules, including central data management, GIS map, user management, and Action Center, serve as the core of the system. Additional modules for traffic signal control and traffic management including, but not limited to, variable message sign control, traffic signal control, floating car data and statistics tools, can be included based on customer requirements. Third-party systems can also be integrated using standard as well as proprietary interfaces.

## First look {#First-look}

Symphony’s main window consists of following areas:

1. **First level navigation** - allows you navigating between modules
2. **Second level navigation** - gives you access to second-level dialogs that belong to the same module
3. **Main application view** - displays currently selected module or view
4. **Action center** - shows all your inbox messages and pending actions
5. **Notification area** - info about new notifications
6. **User menu** - gives you access to user help, personal settings or log out
7. **System alerts** - here you will eventually see application-wide alerts, like missing connection
