# Navigation

## Navigate between modules {#Navigate-between-modules}

The top navigation bar shows available modules. If there is no enough space, remaining modules can be accessed under the **More** menu.

In case a module consists of multiple dialogs, these can be accessed from a navigation bar on the left.

* To navigate to a module, simply click a menu item on the top navigation bar or in **More** menu.
* To navigate to a second-level dialog, click a menu item on the left navigation bar.
* Click **Collapse** («) to collapse the left navigation bar in case you need more space.

:::info

Menu structure depends on individual system configuration and user permissions.

:::

## Navigate in modules {#Navigate-in-modules}

Some modules use also third level navigation to access individual dialogs, typically object details. These dialogs are represented by closable tabs - right under the application header.

![WDF tabs.png](/assets/1256849551_wdf-tabs.png)

* Open a new dialog within current module. The dialog will be represented by a closable tab.
* Click **Close** (×) on the tab to close the dialog.
* Optionally, open tab’s context menu (via right click), and select **Close all** to close all open dialogs within current module.

## Search for modules (Quick navigation) {#Search-for-modules-Quick-navigation}

You will find a magnifying glass symbol in the navigation header. You can use this to jump quickly and directly to individual Yutraffic Symphony functions. Simply enter the name of the desired dialog. Suitable hits are offered directly for selection and can be selected using the cursor or the arrow keys.

## Detach views {#Detach-views}

You can detach modules and dialogs into new browser tabs or windows and move them to another screen. These detached views stay connected to the main window.

* To detach a whole module, right-click a menu item on the top navigation bar or in More menu, and select **Detach** from context menu.
* To detach a second-level dialog, right-click a menu item on the left navigation bar, and select **Detach** from context menu.
* Once you close the detached module or dialog, it will be re-attached to the main window.
* **Tip**: Change your browser settings to open links either in new tab or in new window.

## Restore session {#Restore-session}

When you leave the application with some detached views, at the next login you will be offered to restore all detached dialogs from the previous session. That means, you can pick up where you left off last time.

:::info

To allow this functionality, you may need to enable pop-ups in browser settings.

:::

## Customize main navigation {#Customize-main-navigation}

You can modify the default navigation structure to better fit to your common tasks.

1. Go to **User menu** and click **Personalize**.
2. In the Personalize dialog:

   * Toggle modules you want to see in top navigation
   * Drag modules up or down to change their order
3. Close the dialog. Changes are applied immediately.

Alternatively, contact your system administrator to modify default navigation structure for all users.

## Use bookmarks for quick access {#Use-bookmarks-for-quick-access}

Every module or dialog page in the application has an unique URL address. Thus, you can bookmark a page in your browser and re-open it again.

## Switch language {#Switch-language}

Go to **User menu** -> **Language** and select desired language.

## Log out {#Log-out}

1. Go to **User menu** and click **Log out**.
2. When confirmed, you will be logged out of the application and redirected back to Login screen.
3. If there are detached views, all of them will be closed upon logout.
